# ImportExcelEvents

Импорт расписания из Excel в календарь Outlook. Скрипт читает лист с расписанием, где даты и
занятия лежат парами строк, разбирает время из свободного текста ячейки и создаёт события в
выбранном календаре Outlook через COM.

Написан под конкретную боль: расписание приходит таблицей, где время записано как попало —
`18-21`, `18:00-21:00`, `18.00–21.00`, `с 18.00 до 21.00`, — и переносить это в календарь
руками каждый семестр слишком долго.

## Что делает

- Читает лист Excel, где строки идут парами: строка дат, под ней строка занятий на эти даты.
- Из текста ячейки вытаскивает **все** интервалы времени, а не первый попавшийся: в одной
  ячейке может быть несколько занятий на один день, каждое станет отдельным событием.
- Понимает четыре формы записи времени и дедуплицирует одинаковые интервалы внутри ячейки.
- Убирает время из текста, остаток использует как название события.
- Создаёт события в Outlook: напоминание за 15 минут, статус «Занят», категория
  `AutoImportSchedule`.
- Может добавить участников по списку email — из файла, из аргумента командной строки или из
  обоих сразу.
- Ведёт лог в файл и в консоль.

## Категория как способ отката

Все созданные события помечаются категорией `AutoImportSchedule`. Это даёт безопасный
повторный запуск: `--delete-all` удаляет только события этой категории и не трогает
остальной календарь. Расписание поменялось — удалить и импортировать заново.

## Требования

- **Только Windows**: работа с Outlook идёт через COM (`win32com.client`), на других
  платформах скрипт не запустится.
- Установленный и настроенный Outlook (desktop, не веб-версия).
- Python 3.

```bash
pip install -r requirements.txt
```

Зависимости: `pandas` (чтение Excel), `pywin32` (COM-мост к Outlook), `openpyxl` (движок
`.xlsx`), `pytz` (часовые пояса).

## Использование

```bash
# импорт расписания
python importEvents.py --excel-file schedule.xlsx

# с приглашением участников
python importEvents.py --excel-file schedule.xlsx --invitees "a@example.com,b@example.com"

# список участников из файла, по одному email на строку
python importEvents.py --excel-file schedule.xlsx --invitees-file invitees.txt

# откат: удалить все события, созданные скриптом
python importEvents.py --delete-all
```

| Аргумент | Значение |
|---|---|
| `--excel-file` | путь к файлу расписания |
| `--invitees-file` | файл со списком email, по одному на строку |
| `--invitees` | список email через запятую; складывается с `--invitees-file` |
| `--delete-all` | удалить все события категории `AutoImportSchedule` и выйти |
| `--offset-hours` | сдвиг часового пояса в часах, по умолчанию `3` |

При запуске скрипт спрашивает, в какую учётную запись Outlook и в какую папку календаря
писать, поэтому импорт в чужой или рабочий календарь по ошибке не проходит молча.

## Формат исходного листа

Первые две строки листа пропускаются как шапка. Дальше строки читаются парами: чётная —
даты, нечётная — занятия. Ячейка занятия может содержать несколько строк, каждая строка —
отдельное занятие. Строки без распознанного времени пропускаются.

Имя листа и имя файла по умолчанию заданы константами в начале скрипта
(`DEFAULT_SHEET_NAME`, `DEFAULT_EXCEL_NAME`) — под свой формат правятся там.
